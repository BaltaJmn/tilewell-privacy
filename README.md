# tilewell-privacy

Public web of **Tilewell**, a phonics letter tile app for iPhone and iPad. Served at
<https://tilewell.baltajmn.dev/> by GitHub Pages from `main`, behind Cloudflare (CNAME `tilewell` to
`baltajmn.github.io`, proxied), like `humwell-privacy`.

| Path | What it is |
|---|---|
| `index.html` | What the app does, price, support contact. Support and marketing URL in the App Store |
| `privacy/` | Privacy policy. The URL in the app's paywall and in the App Store |
| `legal.html` | Legal notice (LSSI art. 10), same owner details as the other apps' webs |
| `tw/` | Stylesheet and icons |

Terms of use are Apple's standard EULA. The app's code lives in `~/AndroidStudioProjects/Tilewell`.
